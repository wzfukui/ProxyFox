Version boundary
----------------

Live Chrome Web Store version: v1.4.1
Candidate source and ZIP: v1.4.2

Single purpose
--------------

Configure, test, and quickly switch Chrome proxy settings selected by the user.

Privacy policy
--------------

https://proxyfox.io/privacy.html

Do not claim
------------

ProxyFox is not a VPN or proxy provider. It does not unblock regional content,
provide anonymity, read or modify page content, or automatically choose a
different proxy per website. Configurations are stored locally, but optional
proxy credentials should still be treated as sensitive data.
