# Chrome Web Store listing kit

This directory is a review-ready source pack. It does not publish or modify the live listing.

## Version boundary

- Live Chrome Web Store version: **v1.4.1**
- Candidate source and ZIP: **v1.4.2**
- Upload v1.4.2 only after the maintainer approves a store release.

## Recommended screenshot order

Use the English or Chinese set from `../assets/`:

1. `01-proxy-workspace` — create and manage multiple profiles
2. `02-connection-test` — test before saving and restore the previous state
3. `03-global-bypass` — manage direct-connection rules
4. `04-languages` — five interface languages
5. `05-release-history` — visible version and release history

All screenshots are 1280×800 and were rendered from the real v1.4.2 options-page code with local mock data. They contain no real proxy endpoints or credentials.

## Listing checklist

- Select the locale file that matches the Store locale.
- Keep the single-purpose text and permission explanations consistent with `manifest.json`.
- Link privacy policy to `https://proxyfox.io/privacy.html`.
- Do not describe ProxyFox as a VPN, proxy provider, anonymity product, traffic-unblocking tool, or per-site automatic router.
- Verify the uploaded ZIP version and SHA-256 before submission.
- Preview every locale and image in the Store dashboard before publishing.
