# 简体中文商店文案

## 名称

ProxyFox 代理切换器

## 简短说明

开源 Chrome 代理切换器：多配置、严格认证匹配、直连白名单、连接测试与安全导出，数据仅保存在本地。

## 详细说明

ProxyFox 是一款开源、本地优先的 Chrome 代理切换器，适合需要在开发、测试和企业网络环境之间切换的用户。多个代理配置可以集中管理，不必反复修改浏览器设置。

你可以：

- 创建、编辑、复制、启用和停用 HTTP、HTTPS、SOCKS4、SOCKS5 代理配置。
- 设置全局与配置专用的直连白名单，支持注释和通配符根域名匹配。
- 保存前测试代理，自定义测试地址与超时，并在测试后恢复原浏览器设置。
- 将代理凭据保存在本地，仅在认证请求与当前代理端点严格匹配时提供。
- 导入、导出完整配置；默认不导出凭据，只有用户明确选择时才包含。
- 使用简体中文、繁体中文、英文、日文或韩文界面。

隐私与产品边界：

ProxyFox 的配置存放在设备上的 Chrome 扩展存储中，不包含分析 SDK、广告 SDK 或 ProxyFox 账号系统。ProxyFox 不提供代理服务器，不是 VPN，不读取或修改网页内容，也不会按网站自动选择不同代理。

全站主机权限仅用于让 Chrome 把当前代理端点的认证请求交给扩展处理。源代码和权限检查均公开可审查。

源代码：https://github.com/wzfukui/ProxyFox
隐私政策：https://proxyfox.io/privacy.html

## 单一用途

配置、测试并快速切换由用户选择的 Chrome 代理设置。

## 权限说明

- `proxy`：应用和读取用户选择的 Chrome 代理配置。
- `storage`：在本地保存配置、直连规则、偏好和可选凭据。
- `webRequest`、`webRequestAuthProvider`：仅处理与当前代理端点严格匹配的认证请求。
- `<all_urls>`：让 Chrome 在访问任意目标时都能转交代理认证请求；ProxyFox 不读取或修改网页内容。
