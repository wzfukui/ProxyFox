# 한국어 스토어 문구

## 이름

ProxyFox – 프록시 전환

## 요약

로컬 저장 기반 오픈소스 Chrome 프록시 전환 도구. 여러 프로필, 엄격한 인증 일치, 우회 규칙, 연결 테스트, 안전한 내보내기 지원.

## 상세 설명

ProxyFox는 개발, 테스트 및 기업 네트워크 사용자를 위한 오픈소스 로컬 우선 Chrome 프록시 전환 도구입니다. 여러 신뢰할 수 있는 프록시 프로필을 한곳에서 관리하고 브라우저 설정을 반복해서 수정하지 않고 전환할 수 있습니다.

주요 기능:

- HTTP, HTTPS, SOCKS4, SOCKS5 프로필 생성, 편집, 복제, 활성화 및 비활성화.
- 전체 및 프로필별 직접 연결 규칙, 주석과 와일드카드 루트 도메인 일치 지원.
- 저장 전 연결 테스트, 테스트 URL 및 시간 제한 설정, 테스트 후 이전 설정 복원.
- 자격 증명을 로컬에 저장하고 활성 프록시 엔드포인트와 엄격히 일치할 때만 제공.
- 설정 가져오기 및 내보내기. 자격 증명은 기본적으로 제외되며 사용자가 명시적으로 선택할 때만 포함.
- 한국어, 영어, 중국어 간체·번체, 일본어 UI.

개인정보 및 제품 범위:

설정은 기기의 Chrome 확장 프로그램 저장소에 보관됩니다. 분석 SDK, 광고 SDK 또는 ProxyFox 계정 시스템이 없습니다. ProxyFox는 프록시 서버나 VPN을 제공하지 않으며 페이지 내용을 읽거나 변경하지 않고, 사이트별로 프록시를 자동 선택하지 않습니다.

전체 호스트 권한은 사용자가 선택한 프록시 엔드포인트의 인증 요청을 Chrome에서 전달받는 용도로만 사용됩니다.

소스: https://github.com/wzfukui/ProxyFox
개인정보처리방침: https://proxyfox.io/privacy.html
