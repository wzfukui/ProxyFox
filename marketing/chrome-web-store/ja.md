# 日本語ストア掲載文

## 名前

ProxyFox – プロキシ切替

## 概要

ローカル保存のオープンソース Chrome プロキシ切替。複数設定、厳密な認証照合、除外ルール、接続テスト、安全な書き出しに対応。

## 詳細説明

ProxyFox は、開発、テスト、企業ネットワーク向けのオープンソースでローカル優先の Chrome プロキシ切替ツールです。複数の信頼済みプロキシ設定をまとめて管理し、ブラウザ設定を何度も編集せずに切り替えられます。

主な機能：

- HTTP、HTTPS、SOCKS4、SOCKS5 設定の作成、編集、複製、有効化、無効化。
- 全体および設定別の直接接続ルール。コメントとワイルドカードのルートドメイン照合に対応。
- 保存前の接続テスト。テスト URL とタイムアウトを指定し、テスト後に元の設定を復元。
- 認証情報をローカルに保存し、有効なプロキシの接続先と厳密に一致する場合だけ提供。
- 設定の読み込みと書き出し。認証情報は初期設定では除外され、明示的に選んだ場合のみ含まれます。
- 日本語、英語、簡体字中国語、繁体字中国語、韓国語の UI。

プライバシーと範囲：

設定は端末上の Chrome 拡張機能ストレージに保存されます。分析 SDK、広告 SDK、ProxyFox アカウントはありません。ProxyFox はプロキシサーバーや VPN を提供せず、ページ内容の読み取りや変更、サイト別の自動プロキシ選択も行いません。

全ホスト権限は、ユーザーが選んだプロキシ接続先の認証要求を Chrome から受け取るためだけに使用します。

ソース：https://github.com/wzfukui/ProxyFox
プライバシー：https://proxyfox.io/privacy.html

## 単一目的

ユーザーが選択した Chrome のプロキシ設定を構成、テスト、切り替えること。
