# 繁體中文商店文案

## 名稱

ProxyFox 代理切換器

## 簡短說明

開源 Chrome 代理切換器：多設定、嚴格認證比對、直接連線規則、連線測試與安全匯出，資料僅儲存在本機。

## 詳細說明

ProxyFox 是開源、本機優先的 Chrome 代理切換器，適合開發、測試與企業網路使用者。你可以集中管理多個受信任的代理設定，不必反覆修改瀏覽器設定。

主要功能：

- 建立、編輯、複製、啟用及停用 HTTP、HTTPS、SOCKS4、SOCKS5 代理設定。
- 設定全域與個別代理的直接連線規則，支援註解和萬用字元根網域比對。
- 儲存前測試連線，指定測試網址與逾時，測試後還原原本的瀏覽器設定。
- 將代理憑證儲存在本機，僅於認證要求與目前代理端點嚴格相符時提供。
- 匯入及匯出設定；預設不匯出憑證，只有使用者明確選擇時才會包含。
- 使用繁體中文、簡體中文、英文、日文或韓文介面。

隱私與產品範圍：

設定存放在裝置上的 Chrome 擴充功能儲存空間。ProxyFox 沒有分析 SDK、廣告 SDK 或帳號系統。ProxyFox 不提供代理伺服器，不是 VPN，不會讀取或修改網頁內容，也不會依網站自動選擇不同代理。

全站主機權限只用來接收 Chrome 對使用者所選代理端點送出的認證要求。

原始碼：https://github.com/wzfukui/ProxyFox
隱私權政策：https://proxyfox.io/privacy.html

## 單一用途

設定、測試並快速切換由使用者選擇的 Chrome 代理設定。
