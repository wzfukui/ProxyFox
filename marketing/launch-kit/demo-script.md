# 20-second product demo script

Use the real extension with fictional local data. Never record a real endpoint, username, password, internal domain, or browser history.

| Time | Action | On-screen line |
| ---: | --- | --- |
| 0–3s | Open the popup and show several profiles. | Switch proxies. Keep control. |
| 3–7s | Enable a test profile, then open its editor. | Explicit profiles, one quick switch. |
| 7–11s | Run the pre-save connection test. | Test before saving. Restore after testing. |
| 11–15s | Show global and profile-specific bypass rules. | Direct connections stay readable. |
| 15–18s | Open export and leave credentials excluded. | Credentials excluded by default. |
| 18–20s | End on the logo and URLs. | Open source · local first · proxyfox.io |

## Recording notes

- Keep the browser address bar and extensions context visible at least once so the product is not mistaken for a hosted VPN.
- Use the same fictional `127.0.0.1`, `.example` domains, and placeholder usernames as the store screenshots.
- Avoid speed-up edits during the connection-test result; the state change should remain understandable.
- Add captions; do not depend on narration alone.
