# Facts and claims guardrail

## Safe claims

- Open-source Chrome extension using Manifest V3.
- HTTP, HTTPS, SOCKS4, and SOCKS5 profile management.
- Global and profile-specific bypass rules.
- Pre-save connection testing with restoration of the previous proxy setting.
- Proxy credentials stored in Chrome extension storage and exported only after an explicit opt-in.
- Authentication requests are matched against the active proxy endpoint.
- Simplified Chinese, Traditional Chinese, English, Japanese, and Korean interfaces.
- No ProxyFox account, advertising SDK, or analytics SDK in the current codebase.

## Claims that require fresh verification before use

- The version currently live in the Chrome Web Store.
- Performance measurements and percentage improvements.
- Browser compatibility beyond the declared Chrome minimum version.
- Store ratings, install counts, GitHub stars, contributors, or download counts.
- Any external endorsement, comparison outcome, or “best” ranking.

## Do not claim

- ProxyFox is a VPN, proxy service, anonymity product, security shield, or privacy guarantee.
- It unlocks regional content or defeats access controls.
- It automatically routes each website through a different proxy.
- It reads, filters, modifies, or protects page traffic.
- Local storage makes credentials encrypted or risk-free.
- It is a drop-in replacement for every SwitchyOmega feature.
- Chrome certificate warnings should be bypassed or ignored.
