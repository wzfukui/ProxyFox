# ProxyFox launch kit

This kit supports an account-free preparation workflow. Nothing here has been posted, emailed, or submitted.

## Positioning

**Switch proxies. Keep control.**

ProxyFox is an open-source, local-first Chrome proxy switcher for developers, testers, and enterprise-network users who already have proxy endpoints and want clear, inspectable control over them.

## Best initial audiences

1. Developers and QA engineers who switch among local, test, and office networks.
2. Enterprise IT users who need authenticated proxies and explicit bypass rules.
3. SwitchyOmega users who want a maintained Manifest V3 option and can accept ProxyFox's simpler scope.
4. Open-source users who value local storage, auditable permissions, and credential-safe exports.

## Organic launch sequence

1. Publish the v1.4.2 release and update the Chrome Web Store listing only after maintainer approval.
2. Use one technical launch post first; lead with the workflow problem and the permission model, not generic “productivity” claims.
3. Link to one matching guide page instead of sending every audience to the homepage.
4. Reuse the same factual screenshots and disclosure across channels.
5. Record questions and objections as candidates for FAQ and guide updates; do not invent testimonials or usage figures.

## Measurement without analytics

The current site deliberately has no analytics dependency. Until an explicit privacy decision is made, use only public, aggregate signals available without adding trackers: GitHub stars/issues, release downloads, Chrome Web Store review themes, and recurring support questions. Do not claim attribution or conversion rates that cannot be measured.
